# Intelligence Genealogy

The domain preserves the evolutionary lineage of COS intelligence.

```text
HISTORICAL MATERIAL
      ↓
DRILLS / CCAMEL 360
      ↓
CLASSIFIER
      ↓
PATTERNS
      ↓
REUSE / TRANSFORM / KNOWLEDGE-RESCUE / DISCARD
      ↓
SUPERSESSION
      ↓
FUTURE RELEVANCE
      ↓
EVO
      ↓
NEW BASELINE
```

The purpose is not to preserve every historical artifact. The purpose is to retain the high-value evolutionary knowledge that can explain the current intelligence baseline and its lineage.

## Classifier as depth memory

The classifier is a Curator Tool and acts as memory of research depth.

For every investigated object, it should make visible:

- drills already performed;
- CCAMEL 360 coverage when used;
- dimensions already examined;
- findings recovered;
- superseded knowledge;
- reusable components;
- transformed components;
- discarded material;
- unresolved frontier.

This prevents archaeology from restarting after the research phase has already exhausted an object.
