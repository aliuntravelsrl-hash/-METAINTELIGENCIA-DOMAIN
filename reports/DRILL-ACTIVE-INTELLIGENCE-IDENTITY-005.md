# DRILL — ACTIVE INTELLIGENCE IDENTITY 005

## Objective
Determine the minimum transversal inclusion rule required to derive `ACTIVE REFERENCES` without creating a new authority or duplicating existing COS mechanisms.

## Current evidence

`VERSION.md` establishes that Intelligence Version represents the state of COS intelligence, not a software release, and that a new baseline requires authorized and verifiable evolution. It also requires evidence before advancing the baseline.

`ARCHITECTURE.md` defines the functional TO-BE chain and explicitly preserves the rule `REUSE → TRANSFORM → DELTA/GAP → EVO → NEW MATERIALIZATION`.

`GENEALOGY.md` already provides the evolutionary lineage through Drills, CCAMEL 360, Classifier, classification, supersession, Future Relevance, EVO and new baseline.

Existing COS mechanisms independently provide governed state for knowledge, capability, integrity, supersession, baseline and constitutional reference.

## Finding

The investigation does not justify a new authority for intelligence composition.

The remaining gap is narrower:

**a deterministic inclusion/composition rule that selects the currently active governed references from existing sources.**

The rule must answer:

1. Which references are mandatory for the intelligence scope.
2. Which source governs each reference.
3. What validity condition each reference must satisfy.
4. How superseded references are excluded.
5. How the selected references are serialized deterministically.
