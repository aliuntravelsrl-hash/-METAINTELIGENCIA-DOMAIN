# Metaintelligence Architecture

## Functional chain

```text
DECISION CONTEXT
      ↓
REQUIRED CAPABILITY
      ↓
CAPABILITY RESOLUTION
      ↓
CAPABILITY
      ↓
EXECUTABLE MECHANISM
      ↓
EXECUTION
      ↓
RESULT
      ↓
EVIDENCE
      ↓
VERIFICATION
      ↓
LEARNING
```

This is a **TO-BE functional chain**. It describes what the COS needs to be able to demonstrate; it is not a claim that every link already exists physically.

## Intelligence control

Metaintelligence governs the knowledge around this chain:

- what was learned;
- where the knowledge came from;
- how deeply it was investigated;
- what survived classification;
- what was superseded;
- what remains unresolved;
- what evolutionary recommendation follows;
- what became a demonstrated new baseline.

## Reuse before creation

Existing COS components are evaluated against the required function before any new component is proposed.

`REUSE → TRANSFORM → DELTA/GAP → EVO → NEW MATERIALIZATION`

## Authority boundary

The domain does not become constitutional authority. `atlas-cos-v1` remains canonical.
